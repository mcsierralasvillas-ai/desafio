# App del Motorclub Sierra Las Villas

App web instalable (iPhone y Android) del Motorclub Sierra Las Villas · Villacarrillo (Jaén).

Menú: **Raid 2027** (Inscripción · Ruta · Información del evento) · **Información del club** · **Contacto**.

- `js/config.js` · textos, fechas, precios, pagos, teléfonos, ruta y URL del servidor (lo que se toca normalmente)
- `js/app.js` · funcionamiento
- `css/app.css` · diseño (basado en el logo)
- `icons/` · logo e iconos
- `sw.js` · funcionamiento sin conexión (subir `VERSION` en cada cambio)
- `herramientas/generar-ruta.html` · genera `ruta-trazado.json`

Se publica con GitHub Pages desde la carpeta `docs`. El servidor está en `servidor-google/Codigo.gs`.
