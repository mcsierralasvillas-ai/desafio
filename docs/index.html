Cómo funciona

  1. Sigue el tramo marcado en el mapa hasta el siguiente punto.
  2. Al llegar, pulsa Sellar con foto y haz una foto en la que se vea el sitio.
  3. Se desbloquea el siguiente tramo.
  4. Con todos los sellos, ve a a por tu diploma.

Las fotos se guardan en el móvil y se envían solas cuando haya cobertura. No hace falta internet para seguir la ruta si has descargado el mapa.

Seguridad

No uses el móvil conduciendo. Para siempre en un lugar seguro para mirar la ruta o hacer la foto. Esto no es una carrera: disfruta.

Teléfonos de la organización

Instalar la app en el móvil

iPhone: abre la web en Safari → botón Compartir (cuadrado con flecha) → Añadir a pantalla de inicio.

Android: abre la web en Chrome → menú ⋮ → Instalar aplicación (o "Añadir a pantalla de inicio").
